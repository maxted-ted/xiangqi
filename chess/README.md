# 小棋士．西洋棋

「小棋士」系列的第三款：一款給小朋友和初學者玩的**網頁版西洋棋（國際象棋）**。
設計、架構與互動方式都沿用同一個 repo 裡的 [小棋士．中國象棋](../index.html)，
兩款遊戲看起來和用起來都是同一系列。

- **線上遊玩（GitHub Pages）**：<https://maxted-ted.github.io/xiangqi/chess/>
  （repo 在 Settings → Pages 啟用、來源選 `main` 分支根目錄後就能用這個網址；
  象棋本體在 <https://maxted-ted.github.io/xiangqi/>）

## 特色

- **單一檔案**：`index.html` 裡包含全部 HTML／CSS／JS，不需要任何框架、CDN、建置工具或外部圖片
- **完整規則**：所有棋子走法、王車易位、吃過路兵、兵升變（跳出選單讓你挑皇后／城堡／主教／騎士）、
  將軍、將死、逼和；和棋包含 50 步規則、三次重複局面、子力不足
- **電腦對手**：在 Web Worker 背景執行，想棋時畫面不會卡住。
  negamax + alpha-beta（PVS）、置換表、靜態搜尋、走法排序（置換表走法／MVV-LVA／殺手走法／歷史表）、
  空著剪枝、晚走法縮減、將軍延伸、時間限制的反覆加深
- **五級難度**：新手／初級／中級／高級／大師，用搜尋深度、思考時間、失誤率調整。
  新手和初級真的會犯錯（隨機亂走、從「差不多好」的走法裡隨便挑），讓新手有機會贏
- **執白或執黑**：按「開新局」選擇；執黑時棋盤會轉過來
- **雙人同機對戰**：在「對手」按鈕裡切到「雙人」，黑棋會轉 180°，方便兩人面對面玩平板
- **教練橫幅**：提示輪到誰、將軍警告、點棋子時說明它怎麼走（能易位、吃過路兵、升變時會特別提醒）、勝負與和棋原因
- **標準代數記譜（SAN）**：如 `Nf3`、`O-O`、`exd5`、`e8=Q+`、`Qh4#`，含必要的消除歧義（`Nbd2`、`R1a3`）
- **棋子圖鑑**：每種棋子的走法，以及王車易位、吃過路兵、升變、勝負與和棋規則
- **PWA**：manifest 與圖示都內嵌，可以「加到主畫面」全螢幕執行
- **跨裝置**：PC（Chrome／Edge／Firefox）、Android Chrome、iPhone／iPad Safari；
  滑鼠與觸控都能用；手機直向單欄，iPad 直向加寬，桌機與平板橫向改成「左棋盤、右控制」兩欄；
  處理瀏海 safe-area、禁止雙擊縮放、棋盤永遠是正方形

## 怎麼玩

1. 點一顆自己的棋子，綠色**圓點**是可以走的空格，綠色**圓環**是可以吃的棋子
2. 再點目的地就走過去；上一步會用金色格子標出來
3. 兵走到底線時會跳出選單讓你選升變成什麼
4. 「提示」會用綠框標出電腦建議的一步；「悔棋」會退回到上一次輪到你的時候
5. 「對手」按鈕依序切換 新手 → 初級 → 中級 → 高級 → 大師 → 雙人

## 在本機開啟

直接用瀏覽器打開 `chess/index.html` 就能玩（不需要伺服器）。
若想用手機連到電腦測試，可以在 repo 根目錄開一個簡單的靜態伺服器：

```sh
python3 -m http.server 8000
# 然後打開 http://<電腦的 IP>:8000/chess/
```

> 「加到主畫面」與 PWA 功能需要透過 http(s) 開啟，`file://` 下不會出現。

## 測試

```sh
node chess/test.js
```

每次 push 到 `main` 或開 PR（有改到 `chess/`）時，GitHub Actions（`.github/workflows/chess-test.yml`）會自動跑這支測試。

測試會直接從 `index.html` 抽出 `<script id="engine">` 執行（遊戲和測試用的是同一份引擎），檢查：

- perft：起始局面 depth 1–4 = 20 / 400 / 8902 / 197281，以及 Kiwipete、Position 3／4／5 等標準測試局面
- 王車易位（被將軍、經過被攻擊的格子、國王或城堡動過、城堡被吃）
- 吃過路兵（只能立刻吃、吃完會被橫向將軍時不能吃）
- 兵升變（四種選擇、吃子升變、黑方升變、悔棋還原）
- 將死、逼和、SAN 記譜與消除歧義
- 50 步規則、三次重複局面、子力不足
- AI：找到一步將死、不在優勢時走成逼和、時間限制、低難度會提供多個候選走法
- 隨機＋引擎自我對弈，確認整局每一步都合法
